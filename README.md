# Fridge Panic! 🧊😱
Free Android prototype for tracking food and prioritizing what to eat first.

## Build
Open the **Actions** tab, select **Build Android APK**, and run the workflow. Download the **Fridge-Panic-debug-APK** artifact when the build succeeds. Extract the ZIP to get `app-debug.apk`.

## Prototype limitations
This first test build supports adding and marking food as used, but entries reset after closing the app. Camera scanning, saved offline storage, and recipes are planned, not implemented. Use-by estimates are manually entered and are not food-safety advice.

Built with Kotlin and Jetpack Compose. No paid API required.
